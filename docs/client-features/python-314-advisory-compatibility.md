# Retired Python 3.14 advisory workflow

The dedicated Python 3.14 advisory workflow and its planner were retired when
adopting the Python 3.15 production image. Its historical runs remain historical
evidence; this retirement does not change Python package support metadata.

Required Python 3.12 quality and complete-source tests, browser and live checks,
and production-image verification remain in their existing workflows. The shared
locked-dependency policy and native shard planner remain active.
